# Description
Many Students are forced to do Afficient Math, which counts into their grade, and some of them are punished due to some "unappropriate action" by changing their password, which is ridiculous. This Tool is here to solve the Problem, by providing you the ability to restore your account password.

# Usage
> [!WARNING]
> Make sure to install CORS Everywhere or similiar extensions

Enter the [website](restore.downsicient.us.kg)

Select the thread count you want, default is 100, which is already enough. Change accourdingly.

Select the API, it's either the student account or teacher account.

Type your username into the field.

Click Start.

Wait until the password pops out!
